Bagaimana Fitur Ini Ditambahkan?

Halo Hernan! Saya (Yanto) membuat halaman baru riwayat.html dan menghubungkannya ke index.html, style.css, dan script.js yang sudah ada. Dengan Git Branching, kita tidak perlu memisah folder per orang. Cukup buat branch baru, lakukan perubahan pada file proyek, lalu satukan kembali melalui Merge!

📌 Perintah Git yang dipakai Yanto:

# 1. Yanto membuat branch baru
git checkout -b feature/yanto-riwayat-pekerjaan

# 2. Yanto menambahkan file baru & commit perubahan
git add .
git commit -m "feat: tambah halaman riwayat.html oleh Yanto"

# 3. Yanto kirim branch ke GitHub
git push -u origin feature/yanto-riwayat-pekerjaan
